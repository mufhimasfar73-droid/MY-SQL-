     📌*) Project Overview:
             This project analyzes online course purchase data for a global e-learning platform using a relational MySQL database (elearning_db) consisting of three linked tables: learners, courses, and purchases. The objective is to evaluate customer spending behavior, top-selling courses, category-level revenue, cross-category engagement, and unpurchased catalog inventory through SQL joins, aggregations, and analytical queries (Q1–Q5) to support data-driven marketing and product recommendations.
      📌*)What This Project Covers at a Glance:
              ##🎯Business Goal: Understand sales trends, learner purchasing behavior, and high-performing course categories across international markets.   
              ##🏗️Database Design: A 3-table relational schema connecting learners (user profiles and country) and courses (course titles, categories, and pricing) through a purchases transaction table using Primary and Foreign Keys.   
      📌*)SQL Techniques Applied:
              ##📐Schema & Data Setup: Creating tables with constraints (PRIMARY KEY, FOREIGN KEY, CHECK) and inserting structured sample records.  
              ##🗂️Multi-Table Exploration: Combining records using INNER JOIN, LEFT JOIN, and RIGHT JOIN with 2-decimal currency formatting and clear aliases.   Business Analytics (Q1–Q5): Using SUM(), COUNT(DISTINCT ...), GROUP BY, HAVING, ORDER BY, and LIMIT to answer five key business questions.  
              ##📊Final Deliverables: A complete, executable .sql script file and a concise one-page executive summary report containing key findings and actionable business recommendations.
